# data-tools

> 常用的数据处理小工具（Python 标准库实现，零依赖）。

## 工具
- [csv_to_json.py](csv_to_json.py)：CSV 转 JSON
- [json_pretty.py](json_pretty.py)：JSON 美化 / 压缩

## 用法
    python csv_to_json.py data.csv > data.json
    python json_pretty.py -i ugly.json -o pretty.json
